Featured Project · Published Research

Parchify — Intelligent Invoice Processing Platform

An AI-powered invoice digitization platform designed to extract structured information from printed and handwritten invoices without relying on fixed templates.

  • Integrated Google Document AI and OCR for invoice data extraction.
  • Added image preprocessing including deskewing, cropping and noise reduction.
  • Designed a confidence-based validation layer that flags low-confidence fields for human review.
  • Built the frontend using React.js and Tailwind CSS, with a Python/FastAPI backend and SQLite storage.
  • Added export support for Excel, PDF and JSON.
  • Built a vendor-agnostic pipeline achieving 94.3% OCR accuracy and a 91.2% field extraction F1 score, with 88.5% of invoices passing automated validation and manual review reduced to just 11.5% of volume.
  • Co-authored research based on the framework, published in the International Journal of Computer Applications.

Generative AI · RAG

PDF-based RAG Q&A System

  • Building a locally-hosted RAG pipeline that lets users upload unstructured PDFs and ask natural-language questions grounded strictly in document content.
  • Full stack: PDF ingestion (PyMuPDF), text chunking, embedding generation (Sentence Transformers), vector storage and semantic retrieval (ChromaDB), and local LLM-based answer generation (Qwen3 via Ollama).
  • Implemented a document-grounded prompting strategy that restricts the LLM to retrieved context and explicitly flags when an answer is not present in the source PDFs.
  • Provides source and page-level citations for generated answers to reduce hallucination.
  • Currently extending the MVP with multi-PDF ingestion, improved semantic chunking, retrieval/answer evaluation, and a Streamlit-based chat interface.
  • Public GitHub release and documentation planned next.
